# 1С: Экзамены — релизы

Публичный репозиторий для опубликованных сборок приложения «1С: Экзамены». Исходный код приложения хранится отдельно.

Перед установкой скачивайте APK только со страницы нужного релиза и сверяйте SHA-256 из описания релиза. APK с подписью Android Debug предназначен для тестирования. Его нельзя обновить поверх APK, подписанного другим ключом; для перехода на production-подпись может потребоваться удаление тестовой версии.
